> 本文件由第二轮 26 条交互式提示词归纳而成，重组为可供自主 loop 编程 agent 一次性理解并执行的结构化任务。

## 角色

你是一个自主编程 agent。请按下方规格，从仅含设计文档的空仓库开始，分阶段构建整个项目，每完成一个阶段就自检（编译 / 运行 / 构建通过）再进入下一阶段，全程不需向我确认，遇到歧义时按工程惯例选最合理方案并记录决策。

## 项目背景

## 阶段一：文档与项目规范

5. 设计 `docs/images/logo.svg`：几何羚首徽标（双长直角为符号），README 顶部居中引用，并修复 `docs/oryxos.md` 的图片引用路径。

## 阶段二：Maven 工程骨架（9 模块，可编译可运行）

6. 父 POM `io.oryxos:oryxos` 1.0.0-SNAPSHOT，parent = spring-boot-starter-parent 3.5.0，Java 21，UTF-8；dependencyManagement 覆盖 8 个内部模块与全部三方依赖。
7. 9 个模块及依赖：core（无依赖）；provider→core；storage→core（JPA+SQLite）；memory→core+storage；tool→core；channel-cli→core；web→core；cli→core+channel-cli；boot 聚合全部并打 fat JAR。
8. **依赖版本必须先经 registry metadata 核实再写**（阿里云 `maven-metadata.xml`），不凭记忆：Spring AI Alibaba GA 后用 `spring-ai-alibaba-bom:1.1.2.3` + `spring-ai-alibaba-starter-dashscope`（老坐标 spring-ai-alibaba-starter 已停更）；`sqlite-jdbc:3.53.4.0`；`hibernate-community-dialects:6.6.15.Final`（对齐 Boot 管理的 Hibernate）；springdoc 2.8.9；picocli 4.7.6。
9. 最小源码：各模块 `package-info.java` 固定包名与职责；boot 提供 `@SpringBootApplication` 主类；`application.yaml` 配 8080、virtual threads、`jdbc:sqlite:.oryxos/oryxos.db`、SQLiteDialect、`ddl-auto: none`、`${DASHSCOPE_API_KEY:sk-placeholder}` 占位（dashscope starter 启动强制要 key）。
10. boot 用 spring-boot-maven-plugin repackage 出 fat JAR，且必须**能启动**：验证 Started 日志、8080 端口、swagger 200、`.oryxos/oryxos.db` 生成。
11. `oryxos-cli` 提供 Picocli 主入口 `OryxOsCli`（无参打印版本横幅，支持 `--version` / `--help`）+ `OryxOsVersionProvider`（版本号读 JAR 清单 Implementation-Version，不写死）；main 里把 `System.out` 重绑 UTF-8（Windows 默认 GBK 会与 picocli 的 UTF-8 输出混排乱码）。
12. 运行 fat JAR 必须用 `.tools/jdk-21/bin/java`（全局 JDK 17 会报 UnsupportedClassVersionError）。

## 阶段三：版本控制与同步脚本

13. `git init -b main`，remote 指向 `kissyoudyb/orysos.git`；`.gitignore`：`target/`、`.oryxos/`、`.tools/`、`.tmp/`、`node_modules/`、`website/.vitepress/cache|dist/`、IDE 文件。
14. 提供 `scripts/package.sh`（参考姊妹项目同名脚本）：四路收集变更（已提交未推送 / 工作区 / 未跟踪 / 本地已删除）→ tar.gz → scp 上传 → 远端 pull/解包/删档/commit/push GitHub（3 次指数退避重试），本地只 commit 不 push；**同步目标用环境变量注入**：`ORYXOS_SYNC_HOST`（必填，缺失即报错）、`ORYXOS_SYNC_DIR`（默认 `/root/orysos`），不硬编码任何服务器地址入库。

## 阶段四：官网（website/，VitePress 1.6.4）

15. VitePress 单依赖，`package.json` 放在 `website/` 内（dev / build / preview），版式参考 mq9（RobustMQ 的 Agent 消息项目）八段式主页。
16. 配置要点：`base: '/orysos/'`（GitHub Pages 项目页）；**不开 cleanUrls**（Pages 不支持无 .html 链接）；`appearance: 'force-light'`；sitemap、OG meta、favicon/logo。
17. 中英双语 locales（root=English，zh=中文，nav/sidebar 各一套）；**语言切换器不要配置 locale 的 `link`**——配置了会被二次拼接 base 产生 `/orysos/orysos/zh/` 404，省略后自动按当前页路径推导对应语言页（还能保持当前页不丢）。
18. 自定义主题：extends DefaultTheme，注册全局 `Home` 组件，`custom.css` 定义品牌 token——**配色对齐 era.phadsci.com 实测渲染**：红色品牌系（brand-500 `#C23531` / 600 `#A82B27` / 400 `#E26358`）+ Tailwind 灰阶（`#f9fafb/#e5e7eb/#6b7280/#1f2937`）、Inter 字体、隐藏暗色开关与默认 footer。
19. 主页 `Home.vue` 八段式：Hero（红橙渐变大标题 `linear-gradient(135deg,#C23531,#E26358)` 透明填充 + 红底胶囊按钮 rounded-full）→ 两个核心问题对比卡（✗×4 vs ✓×4）→ 架构图 → 五大能力卡（含 CLI/YAML/curl 真实示例）→ 八个场景卡 → 三种接入方式 → 10 个 REST 端点总览 → CTA 快速开始；文案全部取自本项目文档，中英双语 `t(zh,en)` 切换。
20. 文档骨架 8 页 × 2 语言（what / quick-start / architecture / capabilities / rest-api / scenarios / roadmap / faq），内容从 `docs/` 浓缩；markdown 里引用 public 资源**不能用带 base 的绝对路径**（Vite 会当模块导入报错）——用相对路径的 md 图片语法或 Vue 里 `withBase()`。
21. 新增 `.github/workflows/deploy-website.yml`：push main 且 `website/**` 变更时 `npm ci` + build + `upload-pages-artifact` + `deploy-pages`（权限 `pages:write` + `id-token:write`），支持 workflow_dispatch 手动触发；提示用户在 Settings→Pages 把 Source 设为 GitHub Actions（此步需网页手动操作）。

## 全局约束（不可违背）

- **一切提交与推送只面向 `https://github.com/kissyoudyb/orysos.git`**，绝不向 oryx-labs/oryxos 推送。
- `docs/prompt/` 是用户禁区：不读、不改、不分析内容；git 提交用户自己的改动可以；提示词日志转录只写新文件、按现有文件名续编号。
- Java 21 不降级；同步执行模型 + virtual thread，不引入响应式。
- ReAct Loop 自实现，Spring AI 只用协议转换 + `@Tool` schema 生成，禁用其自动 tool 执行。
- 多 Provider 用显式 name→ChatModel 映射；沙箱用白名单，不用 SecurityManager；审计表（tool_invocations / llm_calls）核心阶段即落库。
- 依赖版本先查 registry metadata 再写 POM；依赖解析失败时不要反复硬试，先核对坐标。

- website `npm run build` 通过；preview 全端点 200；语言切换双向正确（EN↔ZH 不产生双 base 404）；渲染色值与 era 一致（按钮 `rgb(168,43,39)` 胶囊、标题渐变 135deg 同参数）。
- `git status` 干净、本地与 origin/main 同步，所有提交都在 kissyoudyb/orysos。
